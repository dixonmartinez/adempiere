# AdempiereVertical - Ferretería

## Descripción
Vertical para ferreterías basada en ADempiere ERP.

## Licencia
Basado en https://github.com/dixonmartinez/adempiere (AGPL v3)
Este proyecto mantiene la referencia al repositorio original de la comunidad.

## Módulos incluidos
- Clientes (`MBPartner`)
- Productos (`MProduct`)
- Facturación (`C_Invoice`)
- Pedidos (`C_Order`)
- Reportes (`JasperReports`)

## Configuración técnica
- Java: 17
- Stack: ZK Framework básico, Gradle
- Módulos excluidos: manufactura, nómina, almacén avanzado

## Uso
Servicio mensual para ferreterías locales.
